支持参数 ?groups=demo-group@chatroom,test-group@chatroom 精准指定
2. WebSocket 实时双向流
ws://127.0.0.1:8080/api/v1/ws
3. 上游消息 Webhook (接收外部消息推入)
POST http://127.0.0.1:8080/api/webhook
Python 数据订阅示例
import sseclient, urllib.request, json

url = 'http://127.0.0.1:8080/api/v1/stream'
req = urllib.request.Request(url, headers={'Accept': 'text/event-stream'})
client = sseclient.SSEClient(urllib.request.urlopen(req))

for event in client.events():
    msg = json.loads(event.data)
    print(f"[{msg['group_name']}] {msg['sender_name']}: {msg['content']}")
